**Unzip anywhere and run Neria.exe.** The first start downloads yt-dlp, FFmpeg, Deno, mpv and gallery-dl into a `bin` folder next to it; nothing is installed on your PC. Windows SmartScreen may warn because the exe isn't signed yet: More info → Run anyway. Already on 0.5? Neria offers the update itself.

This release is all about the **Compress** page.

### Say where it's going, not how many kbps
- Pick a goal: **For Discord** (20 MB), **For email** (18 MB, so it still fits a 25 MB message once mail has packed it), **For WhatsApp** (16 MB), **Smaller, still sharp**, **As small as possible**, or your own size.
- Every goal says **what it'll look like for this video** before you pick: "1080p, looks the same", "720p 30 fps, a bit softer", "blurry", and how big it'll be ("about 48 MB").
- When a goal can't work, it says so: already small enough to send as it is, too long to look OK (with **"Keep the first 1:40"**, which trims it to the longest part that does), or a video that won't get any smaller.

### See it before you start
- **Before and after** side by side on the same moment: drag the line (or use ← →).
- "312 MB → up to 20 MB · 94% smaller" up front, the real size and how much smaller after.
- **Play a 10 s sample** made with your settings, in your own video player.

### Several videos at once
- **Open several, open a folder, or drop them** on the Compress page. One goal for all; each video says what it'll get.
- Videos that already fit are skipped, one that fails doesn't stop the rest, and Cancel keeps the ones already done.

### Trim right there
- **Trim…** opens a strip of the video with two grips (or ← →), and a button per chapter. Hints and sizes follow the part you keep.

### Advanced, in plain words
- **Plays everywhere / Smaller / Smallest** instead of H.264 / H.265 / AV1, and "Use my graphics card (faster)". A warning if a smaller format might not play where you're sending it.
- Keeps **every sound track, the captions and the chapters** of films and recordings.
- **Cuts off black bars** around the picture, so the size goes to the picture.
- Old interlaced videos (camcorders, TV) come out smooth.

### Fixes
- Sizes now count MB the way upload limits do, so a 19.6 MB file no longer looks like it's over 20 MB.
- Some graphics cards missed the size and gave up; Neria now redoes it on the processor, which hits it.
- Phone videos recorded sideways no longer come out squashed when made smaller.
