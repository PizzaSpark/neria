**Unzip anywhere and run Neria.exe.** The first start downloads yt-dlp, FFmpeg, Deno and mpv into a `bin` folder next to it; nothing is installed on your PC. Windows SmartScreen may warn because the exe isn't signed: More info → Run anyway.

### New look
- Neria has been redesigned: calmer screens, one clear yellow button for the main action, light and dark themes (follows Windows, or pick in Settings → Appearance), and a new icon.
- Drag a video or audio file onto the window to clip or compress it.

### Fewer dead ends
- Links Neria can't download now say why in plain words (private, removed, age-restricted, not a link…), and what to try.
- When YouTube changes something, Neria updates its downloader on the spot and tries again.
- The first start shows each tool downloading, explains what went wrong if you're offline, and has Try again.
- Neria tells you if its folder can't be written to (e.g. Program Files) and to move it somewhere like Documents.
- Big downloads stop early with a clear message when the drive is nearly full, instead of failing halfway.
- Spotify links explain once where the audio comes from (YouTube Music, checked against Spotify's preview).
- Picking Chrome or Edge for cookies warns that they usually block it; Firefox works best.

### Help and updates
- Settings → About shows the versions and has **Copy report**; failed downloads have a **Report** button. Paste it to whoever helps you.
- Neria checks for new versions at start-up and can update itself in place (your settings and tools stay).
