Audio tools: where each one goes

The roadmap lists five sound tools: Convert (MP3, M4A, Opus, FLAC, WAV, and "Extract audio" from a video), Even out loudness across songs, a Tag editor (many files at once, "Find tags online"), Organize (Artist / Album folders, playlists, duplicates) and Split / remove silence. Half of that already has a home: Compress already makes M4A / MP3 / Opus from a sound file and evens out volume, the Clip page already splits by chapters and trims, the Library already knows every song and playlist. So the first question is whether these get a page of their own or join the places that do the nearest thing.

Chosen 2026-11-24: 1B, 2A (+ Even out as an album), 3A, 4A, 5A (+ Duplicates as a filter), section 6 as drawn (the PICKs below).

Ground rules

What it is, and what it isn't

  • Files you have, made into what you need. No new downloading; these work on Neria's own saves and on any file you drop or pick.
  • A copy unless you say otherwise. Convert and Even out write a new file next to the old one (as Compress does); tags are written into the file itself (that's what tags are), with Undo while the toast shows.
  • Moving files is the one exception to the Library's "never moves anything", and only for Organize: you see every move before it happens, the Library's records follow the files, and Undo puts them back.
  • Plain words first, numbers under Advanced. "Plays everywhere" before "AAC 256 kbps"; bit rate, sample rate, mono under Advanced, as on Compress.

2B · One more goal at the bottom, "Just the sound…", that opens the formats

No switch, but a two-step goal in a list of one-step goals, and the size column has nothing to say until you open it.

Even out, as an album

Volume → Even out today brings each file to the same loudness. With several files it gains a second choice: Each the same (a mixed playlist) or As an album (one gain for all, so a quiet ballad stays quieter than the single). No new screen.

Edit tags: one song, or many at once

3A · A dialog with the fields; with several, fields that differ say "Several" PICK

4 · Doing it to several

Picking rows in the Library

4A · A tick on each row's frame on hover (long-press on compact); a bar of what fits them all PICK

Ctrl+click and Shift+click pick too. While any are picked, a bar replaces the filters: how many, then only the actions every picked one can do (Convert, Even out, Edit tags, Put in folders…, Copy files, Remove). Esc or ✕ ends it. A playlist's row picks its songs.

5 · Organize

Put in folders, with every move shown first

5A · A dialog: how to arrange, the moves listed, then Move PICK

From a playlist's ⋯ or several picked songs. Choices in words (Artist / Album, Artist, Album, One folder), where (the Audio folder by default), and the list of moves it will make, with lyrics and covers moving along. Nothing is overwritten: a file already there keeps its place and the move says "already there". A playlist's .m3u8 is rewritten to the new places. Undo afterwards.

Duplicates

A Duplicates choice in the Library's Filter (only shown when there are any): the same song twice (same Spotify id, or the same sound by fingerprint, as the match check already does), grouped, the bigger or newer one ticked to keep, the rest to the Recycle Bin.

6 · Split and silence

On the Clip page, mostly there already

  • By chapters: the clip list's "Add all chapters", then Export with "a file each". Nothing new.
  • By timestamps you paste (a description's "0:00 Intro, 3:12 …"): the clip list gets Paste times…, which turns pasted lines into named clips.
  • Cut silence at the ends: a tick in the Sound dialog (Clip page) and in Compress's Advanced for sound, for recordings that start with a minute of nothing.
