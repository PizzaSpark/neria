Neria: three design directions

The same Download page in each style, with a link preview and a queue showing one download in progress, one done and one failed. Today's version is first for comparison. These are looks, not finished screens: pick a direction (or mix parts) and it becomes the design system for the UI foundation work.

D · Studio + Play

A's calm, B's friendliness · one system, two themes

The rule that makes the mix work: calm where you read and watch, playful where you touch. The queue, stats and preview use A's structure (lines instead of cards, monospace numbers, a big thumbnail). Anything you can press gets B's chunky treatment (thick outline, hard shadow, sticker yellow), so it's obvious what's clickable, which is the UX-first part. The friendly bold headline and copy come from B too.

Touch = playfulButtons, chips, the logo and toggles: 2px outlines, a hard offset shadow on the main action, sticker yellow. They look pressable.
Read = calmQueue rows, progress and numbers: hairlines, a muted palette, monospace stats. Easy to watch for an hour.
Status = soft tagsSaved and Gone are small tinted stickers, not outlines, so green and red stay meaningful.

A · Studio

refined dark, pro tool

Feels like a pro video tool (Linear, Raycast, a camera app). Near-black with one hot "record light" orange instead of purple. Hairlines instead of cards: the queue is a list, not a stack of boxes. A tighter type scale with monospace numbers for sizes and timecodes, a big thumbnail so the content leads, keyboard hints, and a slim icon sidebar. The safest option, and the closest to today's code.

B · Soft neo-brutal

bold, playful, light

Cream paper, black ink, 2px outlines and hard offset shadows, with sticker-like yellow and pink. A heavy grotesk display font. Very distinctive and fun, and nobody would call it generic. The cost: it's loud for an app you watch for a while, the status colours have to fight the outlines, and it needs a real dark mode designed separately.

C · Analog

warm, editorial, media library

Feels like a record shop or tape deck: warm brown-black, paper-coloured text, an amber accent, and a serif display font (Instrument Serif) for titles, so Neria has a voice. The queue reads like a track list (01, 02, 03) with timecode columns. Suits the music and Spotify side well, and the most memorable of the three. Riskier for dense screens like the clipper, and it needs good font loading in Slint.
