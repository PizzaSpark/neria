# Bundled fonts

Embedded into the Neria exe by Slint (see `ui/theme.slint`). All under the SIL Open Font
License 1.1 (license texts next to this file). Latin subsets from Fontsource
(`cdn.jsdelivr.net/fontsource`); other scripts fall back to the system fonts.

| File | Family | Source |
| --- | --- | --- |
| `space-grotesk-*.ttf` | Space Grotesk 500, 700 | Florian Karsten, `OFL-SpaceGrotesk.txt` |
| `inter-tight-*.ttf` | Inter Tight 400, 500, 600 | Rasmus Andersson, `OFL-InterTight.txt` |
| `jetbrains-mono-*.ttf` | JetBrains Mono 400, 500 | JetBrains, `OFL-JetBrainsMono.txt` |
